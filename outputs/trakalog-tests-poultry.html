Ce document liste tous les tests à effectuer sur l'app Trakalog (app.trakalog.com). Pour chaque test, indique ✅ si ça marche ou ❌ + une description du problème si ça ne marche pas. Envoie tes résultats à Yannick.

Stems, Documents, Pack & Commentaires

☐ Test 1.1 Upload et lecture d'un Stem
Comment faire
  1. 1Ouvrir un track dans TrackDetail
  2. 2Cliquer sur l'onglet « Stems »
  3. 3Uploader un fichier WAV ou MP3
  4. 4Cliquer Play sur le stem → vérifier que l'audio joue
  5. 5Cliquer Download → vérifier que le fichier se télécharge
  6. 6Fermer l'app, revenir 1h+ plus tard → rejouer le stem (ne doit pas donner d'erreur)
Résultat attenduLe stem se joue et se télécharge sans erreur.

☐ Test 8.1 Ajouter une nouvelle version audio
Comment faire
  1. 1Ouvrir un track dans TrackDetail
  2. 2Au-dessus du player, chercher le sélecteur de versions (ex : « Main Version » + bouton « + Add Version »)
  3. 3Cliquer « + Add Version »
  4. 4Uploader un fichier audio différent (V2)
  5. 5Deux tabs doivent apparaître : « V1 ★ » et « V2 »
  6. 6Cliquer sur V2 → le player doit charger la V2
